# BunnyPet 스프라이트 프로젝트

- 보내준 토끼 이미지에서 캐릭터별로 잘라낸 PNG를 사용합니다.
- GitHub Actions에서 Windows x64 실행 파일을 빌드합니다.
- 용량을 줄이기 위해 .NET Desktop Runtime을 포함하지 않는 설정입니다. 실행 PC에 .NET 8 Desktop Runtime(x64)이 필요할 수 있습니다.
- 이미지 분리는 수동으로 잡은 영역이므로 잘린 부분이나 흰 테두리가 보이면 수정이 필요합니다.
- 우클릭 메뉴에서 행동을 바꿀 수 있고, 드래그로 이동할 수 있습니다.
