# 토끼 데스크톱 펫 (C# + WPF)

## GitHub Actions로 빌드하기
1. 이 ZIP의 압축을 풉니다.
2. GitHub에서 새 저장소를 만듭니다.
3. `WpfBunnyPet` 폴더 안의 모든 파일과 폴더를 저장소 최상위에 업로드합니다. 숨김 폴더인 `.github`도 반드시 포함하세요.
4. 저장소의 **Actions** 탭을 엽니다. 안내가 나오면 Actions 사용을 허용합니다.
5. `Build BunnyPet (Windows)` 워크플로를 선택하고 **Run workflow**를 누릅니다. 또는 `main` 브랜치에 파일을 올리면 자동으로 시작됩니다.
6. 빌드가 성공하면 실행 기록을 열고 **Artifacts**에서 `BunnyPet-Windows`를 다운로드합니다.
7. ZIP을 풀고 `BunnyPet.exe`를 실행해 테스트합니다.

## 현재 기능
- 투명 배경, 항상 위에 표시되는 작은 창
- 마우스로 끌어서 이동
- 더블클릭으로 행동 변경
- 우클릭 메뉴: 이동 일시정지/재개, 다른 행동, 종료
- 말풍선 없음
- 이미지 없이도 실행 가능한 코드로 그린 토끼 시안
- 자체 포함 단일 파일 Windows x64 게시 설정

## 참고
- GitHub Actions가 Windows 빌드 머신에서 컴파일하므로 개발 PC에 Visual Studio를 설치하지 않아도 됩니다.
- 자체 포함 배포는 .NET 런타임 설치 요구를 줄여주지만 파일 크기가 커집니다.
- Windows 10 버전/업데이트 상태에 따라 실행 호환성을 확인해야 합니다.
- 회사 PC에서는 보안 정책을 우회하지 말고 승인된 방식으로만 실행하세요.
